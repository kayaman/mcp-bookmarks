# mcp-bookmarks — Slidev deck

Product story for **mcp-bookmarks** (bookmark-native knowledge for agents).

## Run

```bash
cd presentation
npm install
npm run dev
```

Opens the dev server (default [http://localhost:3030](http://localhost:3030)).

## Build static site

```bash
npm run build
```

Output is under `dist/` (path may vary; see CLI output).

## Export PDF / PPTX

```bash
npm run export
```

May require Playwright/Chromium; see [Slidev export docs](https://sli.dev/guide/exporting).
